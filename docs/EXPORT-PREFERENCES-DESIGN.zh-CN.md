# v1.2.1：可选记住导出偏好

日期：2026-09-19。状态：已实现于 **1.2.1**；验收情况见 [TESTING.md](TESTING.md)。

本文保留「手动保存为默认，下次自动填入」的设计依据与交互规则。

## 1. 使用目标

经常填写相同作者、水印或开启导出时间的用户，可以把这些选项保存为当前 vault 的默认值。以后打开任意 Canvas 的导出窗口时自动填入，仍然可以为某次分享临时修改。

默认行为保持当前版本的体验：首次使用时没有已保存偏好；只有点击「保存为默认」才会持久化。成功导出、导出失败、取消和关闭窗口均不会自动更新默认设置。

入口直接放在现有导出窗口中。1.2.1 提供一套 vault 级默认值，不引入独立设置页、命名预设或每张 Canvas 单独配置。

## 2. 保存范围

| 项目 | 是否保存 | 下次打开导出窗口时的行为 |
| --- | --- | --- |
| 显示作者 | 是 | 恢复保存的开关 |
| 作者文字 | 是 | 恢复文字；关闭显示作者时也保留，方便再次启用 |
| 显示导出时间 | 是 | 恢复开关；实际时间仍在本次开始导出时生成 |
| 背景水印开关 | 是 | 恢复开关，开启时直接显示水印字段和预览 |
| 水印文字 | 是 | 恢复文字；关闭水印时保留已填写的文字 |
| 水印不透明度 | 是 | 恢复 4%–16% 的设置 |
| 页面标题 | 否 | 使用当前 Canvas 名称，允许本次修改 |
| 输出路径、文件名 | 否 | 使用当前 Canvas 旁边的同名 HTML 路径，继续保留重名编号规则 |
| 实际导出时间、导出 ID | 否 | 每次导出重新生成 |
| 浏览器背景色、搜索、Badge 条件、字号和画布位置 | 否 | 沿用各自现有行为，与插件默认设置独立 |

保存的是明确列出的偏好字段，不直接序列化整个 `ExportOptions`、表单或导出结果。已关闭的作者和水印即使在插件偏好中保留文字，也仍由现有导出逻辑省略，不能进入 HTML 的正文、脚本、注释或额外配置。

初始值：显示作者关闭，作者为空，显示时间关闭，水印关闭，水印文字为空，不透明度 8%。

## 3. 窗口布局与文案

在水印区域之后、现有网络说明和导出进度之前增加一个紧凑的「导出偏好」区域。其两个按钮使用普通按钮样式，「导出」继续作为窗口的主操作。

```text
保存位置       [当前 Canvas 路径.html                 ]
页面标题       [当前 Canvas 名称                      ]
显示作者       [开关]  [作者姓名                       ]
显示导出时间   [开关]
背景水印       [开关]
               （开启时显示文字、不透明度和预览）

导出偏好
在此 vault 中记住作者、时间显示和水印设置。
[保存为默认]   [清除默认设置]
已载入默认设置；修改仅用于本次导出，保存后才会更新默认值。

（现有网络说明、导出状态和进度）
                                      [取消] [导出]
```

| 场景 | 中文 | 英文 |
| --- | --- | --- |
| 区域名称 | 导出偏好 | Export preferences |
| 说明 | 在此 vault 中记住作者、时间显示和水印设置。标题和保存位置按当前 Canvas 生成。 | Remember author, time display, and watermark settings in this vault. The title and output path follow the current Canvas. |
| 保存按钮 | 保存为默认 | Save as defaults |
| 清除按钮 | 清除默认设置 | Clear saved defaults |
| 没有保存记录 | 当前设置仅用于本次导出。 | These settings apply to this export only. |
| 已载入 | 已载入默认设置；修改仅用于本次导出，保存后才会更新默认值。 | Saved defaults loaded. Changes apply to this export until you save them as defaults. |
| 保存中 | 正在保存默认设置… | Saving defaults… |
| 保存成功 | 已保存。下次打开导出窗口时自动填入。 | Defaults saved. They will be filled in next time you open the export dialog. |
| 清除成功 | 已清除默认设置。本次填写保持不变，下次打开使用初始设置。 | Saved defaults cleared. Current fields are unchanged; the next dialog will use initial settings. |
| 保存失败 | 未能保存默认设置。本次仍可导出，请重试。 | Could not save defaults. You can still export with the current settings. Try again. |
| 清除失败 | 未能清除默认设置，请重试。 | Could not clear saved defaults. Try again. |

反馈显示在偏好区域自身的状态行，不占用导出进度文本。常规状态使用 `role="status"` / `aria-live="polite"`，错误需能被辅助技术感知。窄屏按钮可以换行，避免增加横向滚动。

## 4. 操作规则

### 打开窗口

插件先完成偏好读取，再让新导出窗口使用其独立副本。填入顺序为当前 Canvas 标题和路径、已保存偏好、控件禁用状态、水印预览。

仅打开窗口不写入插件数据。读取不到数据文件属于首次使用，不显示错误。读取失败或格式不受支持时使用初始值并显示状态说明；不因回退而自动覆盖已有文件。

### 保存为默认

1. 取当前偏好字段的独立快照，按现有导出规则归一化作者与水印文字。
2. 开启水印时检查非空、最多 40 个 Unicode 码点；校验失败定位到原有水印错误和输入框，不保存半套配置。
3. 通过插件保存接口写入，成功后再更新内存中的已保存值，并显示成功状态。
4. 保存本身不导出 HTML，也不关闭窗口。之后取消或关闭窗口不撤销已经完成的保存。

只校验要保存的偏好：用户暂时填错输出路径不妨碍保存默认值；导出时仍由原流程校验路径。关闭的水印文字允许作为未启用草稿保留，重新开启后必须通过现有校验才能保存或导出；不静默截断文字。

第一次可以显式保存一套初始值。已有保存记录且当前偏好与其归一化后的值一致时禁用保存按钮；只修改标题或输出路径不算偏好发生变化。保存后继续编辑偏好时清除过时的成功提示，显示「本次修改尚未保存为默认」。

### 清除默认设置

立即清除持久化的默认配置，成功后下次打开使用初始值。保留当前窗口的字段和水印预览，避免在用户正在准备导出时丢失输入；用户可以再次点击保存恢复这套默认值。

按钮旁的说明或提示明确「只影响下次打开」。已有默认记录时启用清除按钮；读取失败、无法判断是否存在记录时也允许用户显式清除。正常情况下没有记录则禁用。该操作无需额外确认窗口。

### 与导出的关系

点击导出始终使用当前字段的独立快照。偏好是否保存、上一次保存是否成功均不影响本次导出内容。导出运行中和成功后的结果界面，禁用保存、清除及已有表单字段；失败后恢复可操作状态。

偏好写入期间暂时禁用表单、保存、清除和导出，保留关闭窗口能力。保存或清除失败后恢复控件，保留当前输入，不将这类错误显示成「导出失败」。

| 用户操作 | 本次 HTML | 后续导出窗口 |
| --- | --- | --- |
| 修改后直接导出 | 使用本次修改 | 继续载入原来保存的偏好 |
| 修改后取消 | 不生成 HTML | 继续载入原来保存的偏好 |
| 保存为默认后取消 | 不生成 HTML | 使用刚保存的偏好 |
| 保存后再次修改，再导出 | 使用再次修改后的字段 | 使用最后一次显式保存的偏好 |
| 清除默认设置后导出 | 使用当前保留的字段 | 使用初始值 |
| 导出失败或被取消 | 沿用现有失败和取消行为 | 不更新偏好 |
| 偏好保存失败后导出 | 可继续按当前字段导出 | 不承诺失败的写入已经生效 |

## 5. 存储与生命周期

使用 Obsidian 的 `Plugin.loadData()` / `Plugin.saveData()`，由插件管理当前 vault 配置目录中的 `data.json`。这些是官方持久化接口，不硬编码 `.obsidian` 路径，不使用浏览器 `localStorage`。

同一 vault 的 Canvas 共用一套偏好，不同 vault 各自保存。插件不增加网络请求；如果用户已有工具同步插件配置，偏好可能随该配置同步，不能描述为「只保存在这台设备」。

建议的数据结构：

```ts
interface ExportPreferences {
  showAuthor: boolean;
  author: string;
  showTime: boolean;
  watermark: {
    enabled: boolean;
    text: string;
    opacity: number;
  };
}

interface PluginDataV1 {
  schemaVersion: 1;
  exportDefaults: ExportPreferences | null;
}
```

`exportDefaults: null` 表示未保存或已清除。数据格式版本与插件版本分开；保存数据时不加入 Canvas 路径、标题、时间戳或导出内容。清除写入空偏好状态即可，无须手动删除文件。

读取的值视为 `unknown`，逐字段校验并创建新对象：

- 缺失字段回退初始值；布尔字段只接受实际布尔值，字符串不强行转型。
- 作者和水印文字沿用去除首尾空白、合并连续空白的规则。水印不截断 Unicode 字符。
- 不透明度只接受有限数值，按控件步长取整并限制在 4–16；类型错误回退 8。
- 若文件中出现已启用但空白或超长的水印，保留可见内容并显示字段错误，要求修正后导出。不能静默取消用户原本要求的水印。
- 字段损坏导致回退时给予一次状态说明；没有数据文件、没有保存记录以及后续新增字段缺失，正常使用初始值。
- 未知数据格式版本不自动迁移或覆盖。显式保存、清除才允许替换为当前结构。

插件维护已完成写入的默认值，窗口维护自己的草稿；二者的嵌套水印对象也不能共享引用。保存、清除由同一插件实例串行处理，失败不得让后续重试失效。

关闭窗口不取消已明确发起的偏好写入。旧窗口的异步回调不能再更新已移除的 DOM；新窗口等前一次写入结束后再获取默认值，避免读到过时状态。关闭后发生写入错误用简短 Notice 反馈。重开和卸载场景均需避免过期回调误改新窗口状态。

保存或清除失败时不声称持久化成功，内存保留最后一次确认完成的状态；磁盘最终状态由后续成功读取确认，不额外承诺文件写入具备事务回滚能力。

## 7. 验收标准

### 数据与真实窗口流程

1. 从 1.2.0 升级且没有插件数据时，作者、时间、水印仍默认关闭；打开、取消和普通导出不会产生偏好写入。
2. 保存所有六类偏好后重开窗口，控件、预览及实际导出一致；重新加载插件后仍能读取。切换 Canvas 时标题和路径跟随新 Canvas，时间戳重新生成。
3. 临时修改后直接导出、失败重试或取消均不更新默认值；手动保存后取消仍然保留默认值。
4. 作者或水印关闭时允许保留文字，导出 HTML 不含被关闭的作者、水印值；清除默认设置不改变本次输入，下一次打开全部使用初始值。
5. 开启水印但空白、超长时不能保存默认值或导出；HTML 特殊字符及 40 个补充平面 Unicode 字符保持现有行为。关闭水印时保留草稿，再次启用时恢复校验。
6. 读取失败、损坏字段、未知格式、保存失败、清除失败都有明确反馈；当前表单可继续使用。没有发生自动覆盖或未处理 Promise rejection。
7. 模拟慢写入、关闭后立即重开、保存后清除、失败后重试，确认默认值与提示准确，过期窗口不会污染新窗口。
8. 插件级测试验证实际调用 `loadData` / `saveData`，并验证相互独立的 vault 数据实例；不只测试内存对象或控件外观。

### 外观、兼容与发布

- 中英文、深浅主题、正常宽度和 320px 窄屏下检查新增区域的换行、键盘顺序、状态朗读和字段聚焦。
- 在开发 vault 内完成一次真实的保存 → 关闭 → 重开 → 导出 → 插件重载 → 清除流程，并覆盖 Canvas 弹出窗口。浏览器中的最小控件适配器不能替代这次实测。
- 运行 `pnpm check`、新增 `pnpm test:preferences`，以及受影响的元数据和水印浏览器回归；以一份真实导出文件确认原有搜索、阅读和背景功能可用。
- 实现时将 `manifest.json`、`package.json`、`versions.json` 和 `src/export.ts` 的生成器版本统一更新到 **1.2.1**；最低 Obsidian 版本计划仍为 **1.13.7**。
- 更新中英文 README 中「每次恢复默认」的描述、1.2.1 更新日志和验收记录。在发布指南中补充偏好测试命令，并将固定的旧标签示例改为当前 manifest 版本说明。
- 发布包沿用原有三个运行文件，不打包开发 vault 的 `data.json` 或个人偏好；插件正常升级保留用户自己的偏好文件。
