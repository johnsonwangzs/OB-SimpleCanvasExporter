# 导出 HTML 的阅读面板方案

日期：2026-09-17。状态：已在 v0.3.0 实现并完成浏览器及实际导出验证；验收结果见 [TESTING.md](TESTING.md)。以下保留方案与交互约定。

## 1. 目标与范围

在浏览器中阅读导出的 Canvas 时，可以把一张文本卡片的完整正文放到独立面板中阅读。正文不受画布缩放和卡片原始尺寸限制，同时保留画布上下文。

首版包含：文本卡片的阅读入口、单个阅读面板、正文排版与字号调整、与现有搜索联动、键盘操作及窄屏布局。

不包含：视图前进后退、阅读历史、书签、批注、编辑、多面板、比较、面板拖动或手动调宽、目录、新的搜索结果列表。文件、网页和分组卡片不增加阅读能力。已有链接和静态内容继续按导出页原有能力使用。

功能仅作用于新导出的 HTML，不修改 Obsidian 中的 Canvas；已有 HTML 需要重新导出。独立打开即可使用，不需要网络或 Obsidian。

## 2. 布局

推荐桌面端右侧停靠，窄屏切换为单列阅读。

| 项目 | 首版约定 |
| --- | --- |
| 桌面布局 | 面板位于全局工具栏下方、画布右侧；画布使用剩余宽度，仍可操作 |
| 面板宽度 | 默认 480px，最多占可用页面宽度的 45%；不提供拖拽调宽 |
| 窄屏布局 | 页面宽度小于 900px 时，面板占据工具栏下方内容区；关闭后显示画布 |
| 工具栏 | 保持现有缩放与搜索区，允许原有响应式换行；面板不覆盖工具栏 |
| 面板头部 | 固定显示“卡片阅读”、A−、当前字号、A+、关闭按钮 |
| 正文区域 | 独立纵向滚动；不把滚轮传给画布 |
| 原卡片 | 增加“阅读中”标记，位置、尺寸、正文和层叠顺序不变 |

打开或关闭面板时不自动适应全图、不自动缩放，也不自动定位卡片。桌面可用画布宽度改变时保持当前缩放和画布中心对应的坐标；这是布局调整，不记录视图历史。用户在面板打开期间进行的平移和缩放继续保留。

窄屏阅读期间，被遮住的画布不响应指针或键盘焦点。搜索仍可使用；缩放操作仍针对画布，关闭阅读面板后可看到结果。面板不作为屏蔽全局工具栏的模态弹窗。

## 3. 打开、切换和关闭

### 阅读入口

每张有可读正文的文本卡片右上角提供“阅读”按钮。桌面在悬停或键盘焦点进入卡片时显现，触屏保持可见；按钮不能靠悬停才能获得键盘焦点。

入口作为独立的卡片操作装饰，不插入正文排版或随正文滚动。按钮保持可点击的屏幕尺寸；小卡片上的文字可以收为图标，但保留可访问名称。交叠卡片仍遵循原有层叠与命中顺序，不把下层卡片的入口提升到最前面。极小缩放下只对当前悬停或聚焦卡片展示入口，避免按钮堆叠。

不绑定整张卡片的单击或双击：保留选中文字、双击选词、正文链接和卡片滚动的现有操作。

### 面板状态

| 用户操作 | 面板行为 |
| --- | --- |
| 点击一张卡片的“阅读” | 打开面板，显示该卡片完整正文；通常从顶部开始 |
| 有搜索词且该卡片命中 | 打开后在面板内滚动到第一处命中 |
| 点击另一张卡片的“阅读” | 在同一面板替换正文，按上述规则确定初始位置 |
| 再次点击正在阅读的卡片 | 聚焦已有面板，不重置正文或滚动位置 |
| 点击画布空白处 | 保持面板打开，可以继续操作画布 |
| 点击关闭或在面板内按 Esc | 关闭面板，移除“阅读中”标记，焦点回到阅读入口 |
| 关闭后重新打开 | 重新从顶部或第一处搜索命中开始；首版不保存每张卡片的阅读进度 |

手动打开、阅读、调整字号、关闭面板均不改变原卡片的滚动位置。面板切换后释放上一张正文副本，只保留当前一张。

## 4. 正文呈现

- 显示导出文件中已包含的完整静态正文，包括原卡片首屏之外的内容，不重新读取 Markdown 或获取资源。
- 正文按面板宽度重新换行，默认字号 16px，普通正文行高约 1.65；A− / A+ 每次调整 2px，范围 14～22px，达到边界时禁用相应按钮。
- 字号仅影响面板。保留标题层级、加粗、强调、链接、列表、引用、代码和 Badge 的视觉区分；标题及 Badge 以正文为基准保持比例。沿用导出主题的字体与颜色，面板不提供额外主题切换。
- 不直接照搬原卡片的固定宽高、裁切和上下滚动占位。图片不超过正文可用宽度；代码块和宽表格局部横向滚动，不撑宽整个面板。
- 调整字号时尽量保持当前可见段落的位置，不滚回顶部；同一页面内切换卡片、关闭再打开保留字号，刷新后恢复默认值，不增加本地存储。
- 顶栏使用通用标题“卡片阅读”，不重复提取正文第一行作为长标题。正文中已有的标题完整保留。
- 原生文字选择、复制和已有链接行为继续可用。折叠内容在面板中的展开状态独立于原卡片；搜索和字号更新不重新构建整张正文，避免丢失状态。
- 空文本卡片不显示入口；渲染失败但已有文本回退内容的文本卡片可以展示该回退正文，不承诺恢复缺失格式。

## 5. 与 v0.2.0 搜索联动

继续使用全局搜索框，不在面板内新增搜索框或导航按钮。

| 场景 | 约定 |
| --- | --- |
| 面板正文包含当前关键词 | 面板中同步高亮所有可搜索的命中，颜色与画布正文一致 |
| 修改搜索词 | 更新画布和面板高亮；不切换正在阅读的卡片，也不自动改变面板滚动位置 |
| 清空搜索或没有结果 | 保持当前阅读内容和位置，清除对应高亮 |
| 面板打开时使用搜索“上一张／下一张”或 Enter / Shift+Enter | 延续原有画布结果导航，同时把面板切换到该结果卡片，并显示第一处命中 |
| 面板关闭时使用搜索结果导航 | 维持 v0.2.0 行为，不自动打开面板 |
| 点击“查看全部结果” | 调整剩余画布区域的视图，面板保持当前内容 |
| 手动阅读未命中卡片 | 允许打开；面板保持正常亮度，来源卡片临时恢复亮度并标记“阅读中”，不视为命中 |
| 在搜索框中按 Esc | 仅执行现有清空搜索行为，不连带关闭面板；在面板中按 Esc 则只关闭面板 |

**搜索数量和顺序始终以原始画布文本卡片为准。** 正文副本不增加“命中几张／几处”，面板的折叠状态也不改变画布搜索计数。面板内展示的高亮依据副本当前可见内容计算，不需要与画布的可见高亮数量完全相同。

“当前”仍表示搜索定位结果；“阅读中”表示面板来源，两者是独立状态。手动打开另一张卡片不修改搜索当前位置。同一卡片同时具有两种状态时让标记错开显示，不覆盖正文或彼此重叠。

上述搜索导航仍会按照原有行为定位画布及原卡片内的第一处命中。原卡片滚动不变的保证针对面板操作本身，不取消用户主动搜索导航的现有效果。

## 6. 键盘与生命周期

- 入口、字号和关闭均使用原生按钮及中英文可访问名称。首次打开或手动切换时把焦点放到面板内的关闭按钮；搜索导航时保留搜索输入焦点，以便连续 Enter。
- 面板使用有名称的区域，不在桌面端锁住焦点。窄屏只让隐藏画布退出交互，保持全局工具栏和面板可达。
- 面板滚动区域可通过键盘滚动；Esc 不应覆盖输入法组合输入或正文控件自己的优先操作。关闭后回到打开入口；入口不可用时回到画布。
- 正文切换使用简短状态播报，不把整段正文作为 live region 重复朗读。
- 打印时隐藏面板、入口和“阅读中”标记，继续只打印原始画布一次。
- JavaScript 未初始化或不可用时隐藏阅读入口及面板，保持现有静态导出可读性。

## 7. 与当前实现的衔接

以下记录实现约束与代码职责。

| 现有位置 | 需要承担的工作 |
| --- | --- |
| `src/viewer-html.ts`、`src/export.ts` | 添加面板外壳与文本卡片入口；面板放在 `.sce-scene` 外，避免继承画布变换 |
| `src/viewer.ts` | 管理单个阅读来源、正文副本、字号、面板滚动与焦点；把现有搜索导航和高亮接入面板 |
| `src/styles.ts` | 面板布局、正文排版适配、来源标记、响应式及打印规则 |
| `src/i18n.ts` | 补齐阅读、关闭、字号及状态的中英文文案 |
| `src/render.ts` | 原则上复用已有静态正文；仅在无法可靠识别正文边界时补充标记 |

### 正文副本与样式

优先复制 `.sce-render-sizer` 内已有的静态正文，去掉卡片几何和滚动占位；不移动原始 DOM。副本不带 `.sce-card` 或原始 `data-node-id`，不加入原搜索索引。复制内容中的 ID 以及关联的片段链接、ARIA 和 SVG 引用需要一起重映射，避免和原正文冲突。

当前 `StyleBank` 会冻结后代元素的像素字号、行高等样式。**仅给面板根元素设置 `font-size` 不能实现字号调整。** 需要在副本范围内适配字体比例和正文布局，保留标题、Badge、代码等差异；不得修改原始冻结样式或画布 DOM。具体适配以实际 Prism 主题导出为验收样本。

现有 `startViewer` 通过函数序列化嵌入 HTML。新增逻辑必须继续在导出页内自包含运行，不能依赖插件进程或遗漏在闭包之外的运行时函数。

### 搜索与布局

- 保留原卡片索引和计数；正文副本使用独立的命中范围和 CSS Highlight 注册项，关闭或切换时释放。匹配规则复用，但 Range 必须指向副本，不能直接使用原卡片的节点或偏移映射。
- 查询变化和字号变化不替换整张副本；正文折叠状态变化只更新面板自身的可搜索内容和高亮。
- 沿用当前浏览器兼容策略：不支持正文 Highlight API 时，阅读仍正常可用，保持现有搜索降级提示，不为面板单独引入高亮补丁库。
- 面板滚动区域位于画布滚轮事件范围之外。画布可用宽度变化由现有 ResizeObserver 统一补偿中心，避免布局处理与观察器重复移动导致漂移。
- 窄屏由面板覆盖画布，画布通过 `inert` 和 `aria-hidden` 退出交互，同时保留有效布局尺寸，避免零尺寸参与自动 fit 或中心补偿。用户显式使用缩放或适应操作时按最终可用画布尺寸计算。

## 8. 验收重点

1. 长卡片可以从头读到尾；打开、独立滚动、调字号和关闭不改变原卡片的内容或滚动位置。
2. 不同缩放下入口可用；面板正文始终清晰且字号固定；反复开关不造成画布中心漂移或缩放变化。
3. 多张命中时，打开、切换和关闭面板均不使搜索数量翻倍；手动阅读与搜索当前结果保持各自含义。
4. 搜索结果导航能同步切换已打开的面板；普通输入、清空、零结果和“查看全部结果”不打断当前阅读。
5. 实际主题、Badge、长链接、代码、表格、图片及折叠内容无横向溢出或原卡片样式污染；字体 14、16、22px 均检查。
6. 深浅主题、宽屏和 320px 窄屏可阅读，按钮不重叠；鼠标、触屏、键盘及输入法操作符合约定。
7. 重复切换释放旧内容和高亮；离线打开、打印及无 JavaScript 时保持合理行为。

按用户确认以 v0.3.0 实现，不包含视图前进后退或阅读历史。
