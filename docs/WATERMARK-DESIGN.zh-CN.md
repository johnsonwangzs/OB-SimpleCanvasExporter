# 导出 HTML 的斜向背景水印设计

日期：2026-09-18。状态：已实现于 1.2.0；本文保留设计依据与交互规则。正式入口提供开关、文字、不透明度及实时预览，角度固定为 -30°，没有高级设置入口。验收记录见 [TESTING.md](TESTING.md)。

## 1. 结论与范围

实现难度较低。当前 `.sce-viewport` 管理画布背景，`.sce-scene` 单独执行平移和缩放，适合在两者之间加入独立水印层。无需修改 Markdown 渲染、卡片内容、分组几何或连接线生成逻辑。

1.2.0 提供「导出时设置的文字背景水印」：配置与图案随 HTML 保存，接收者离线打开也能看到。水印固定在画布视口，画布拖动和缩放时保持字号、倾角、间距；普通浏览器页面缩放仍会改变它的屏幕尺寸。

这是署名、来源和使用范围提示。背景水印会被不透明卡片及分组背景遮挡，也可以被 HTML 接收者修改或移除；不定位为防复制、防篡改措施。

## 2. 视觉建议

| 项目 | 推荐值 / 规则 |
| --- | --- |
| 文字 | 用户自行输入，例如「项目资料 · 仅供交流」；示例只是占位提示，不自动写入导出 |
| 排列 | 横向重复，相邻行错开半个间距，覆盖整个可见背景 |
| 倾角 | -30°，从左下向右上倾斜 |
| 字体 | 系统无衬线字体，24px，字重 400；不打包远程字体 |
| 不透明度 | 默认 8%，建议允许 4%–16%；数值越高越明显 |
| 间距 | 默认横向约 360px、纵向约 220px；长文本自动增大单元尺寸，避免重叠 |
| 颜色 | 浅色背景使用黑色，深色背景使用白色；仅水印自动适配 |
| 层级 | 纯色背景 → 水印 → 分组 / 连线 / 卡片 → 工具栏 / 阅读面板 |

水印不要进入卡片正文或阅读面板，不参与正文搜索、Badge 筛选和文本卡片统计。不透明分组背景也会遮住水印，这是背景层语义的一部分。半透明卡片、搜索淡化后的卡片会自然透出水印，需要视觉验收。

短文字保持 24px。较长文字先增加平铺单元的宽高，使用旋转后边界加留白计算，不能只固定宽度并裁切文字。建议使用单行、最多 40 个 Unicode 码点，推荐用户控制在 8–16 个中文字符。重复图案在视口边缘正常裁切。

## 3. 导出窗口

在现有「导出标题 / 显示作者 / 显示导出时间」下面增加：

```text
背景水印                                    [关闭 / 开启]
水印文字       [项目资料 · 仅供交流                 ]
深浅           [────────●────────]              8%
样式           倾斜 30° · 标准间距
               （小型实时背景预览）
```

- 默认关闭，沿用当前导出外观；开启后显示文字、深浅和预览。
- 开启但未填写文字时，点击导出在字段旁提示「请输入水印文字」，保留已填选项；不悄悄输出空水印。
- 首版只开放文字和深浅，角度与间距采用推荐值；高级设置作为后续扩展，避免导出窗口过长。
- 输入去除首尾空白，将换行及连续空白归一化为空格；超过长度上限明确提示，不静默截断署名。
- 预览即时变化。导出执行中禁止修改相关字段；点击导出时获取独立配置快照。
- 与当前作者 / 时间选项一致，只影响本次导出，重新打开窗口恢复默认值。若以后需要记住，应单独增加明确的插件设置。
- 水印文字独立于作者与标题，不自动推断身份，也不自动把作者填入水印。
- 导出的阅读页暂不增加水印编辑或隐藏按钮；现有「背景」按钮继续调整底色。

## 4. 渲染方案

使用内联 SVG 的 `<pattern>` 平铺文字，外层只绘制一个填满视口的矩形。图案内部保存少量文本副本及跨边界副本，实现交错排列；不按画布大小生成成百上千个 DOM 节点。

```html
<main class="sce-viewport">
  <svg class="sce-watermark" aria-hidden="true" focusable="false">
    <defs><!-- 已转义文字、旋转和交错平铺 pattern --></defs>
    <rect width="100%" height="100%" fill="url(#sce-watermark-pattern)"></rect>
  </svg>
  <div class="sce-scene"><!-- 原分组、连线、卡片 --></div>
</main>
```

```css
.sce-viewport { isolation: isolate; }
.sce-watermark {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  z-index: 0;
  pointer-events: none;
  user-select: none;
  color: var(--sce-watermark-ink);
}
.sce-scene { z-index: 1; }
```

这是层级示意，实际 CSS 仅在启用水印的 `.sce-watermarked` 上隔离层级，并为静态回退和打印提供完整场景宽高。水印不放进 `.sce-scene`，不使用负 `z-index`，也不覆盖正文。`patternUnits="userSpaceOnUse"` 按 CSS 像素定义平铺尺寸；外层 SVG 不使用缩放整个图案的固定 `viewBox`。

水印的初始颜色、文字、透明度和图案在导出时直接写入 HTML，禁用 JavaScript 时仍可显示初始水印。无脚本的画布是滚动回退，不承诺水印固定在屏幕上；确保图案覆盖完整静态场景。

独立 `src/watermark.ts` 负责类型、参数归一化、图案生成及颜色选择。文字通过 DOM `textContent` 写入 SVG，再由 `outerHTML` 序列化；只接受纯文本，不接受用户提供的 SVG、HTML 或 CSS。数值参数做有限数检查及范围限制，图案 ID 使用内部固定前缀。用户文本不进入脚本或样式插值位置。使用 `fill-opacity` 设置文字深浅，避免打印时产生整组透明度栅格化。

## 5. 与背景、交互、输出配合

### 背景换色

水印颜色跟随 `.sce-viewport` 的实际底色，不只检查导出时的明暗主题。建议把底色转成可比较的 RGB 后，在黑 / 白两种水印色中选择与底色对比更高的一种，再应用用户设置的不透明度。此规则是视觉启发式，需用六种预设及自定义颜色确认效果。

初始导出、恢复已存背景、选色器预览、HEX 提交、恢复导出原色这五条路径均要更新水印颜色。不要改变全局 `--sce-text`，否则工具栏和卡片配色也会变化。解析失败时使用导出时的水印色。

当前 `startViewer` 通过 `toString()` 序列化；水印颜色函数也作为自包含函数序列化，并以第二个参数传入，只在启用水印的导出中内嵌。两者都不引用未内嵌的模块变量。背景颜色变化仅更新水印 CSS 变量，不重建卡片或搜索索引，不重新 fit。

### 输入与布局

- 水印 `pointer-events:none`，拖动画布、滚轮、卡片选择 / 复制、链接、阅读入口保持原行为。
- 不给水印加焦点，不让屏幕阅读器重复朗读装饰文字。
- 窗口缩放与工具栏换行只改变水印层大小，不改变图案字号。
- 控制图案只覆盖画布区域，工具栏、浮层、操作提示和阅读面板保持原外观。
- 关闭水印时不输出 SVG。旧 HTML 需重新导出才能携带此功能。

### 打印

打印时保留水印：当前打印会移除画布 transform，水印容器改为覆盖完整的未缩放场景，并恢复与导出原背景配套的水印色。多页输出按场景连续平铺，不承诺每页固定同一位置或填满场景结束后的纸张留白。已检查打印媒体布局及 Edge 输出的两页 PDF。

## 6. 代码落点与验收

| 文件 | 实现职责 |
| --- | --- |
| `src/metadata.ts` | 给现有 `ExportOptions` 增加可选水印配置 |
| `src/watermark.ts`（新增） | 参数校验、文本归一化、SVG 图案生成 |
| `src/main.ts` | 导出窗口的开关、文字、深浅、预览和错误提示 |
| `src/export.ts` | 在 `.sce-scene` 前插入水印 SVG，输出初始颜色 |
| `src/styles.ts` | 水印层级、静态回退、打印范围 |
| `src/viewer.ts` | 背景应用及恢复时同步水印颜色 |
| `src/i18n.ts` / `styles.css` | 中英文文案、导出窗口样式 |

验收重点：关闭时不输出水印和填写的文字；中英文和 `<>&\"'` 显示正常；超长 / 空白输入有明确处理；缩放和平移不改变图案；320px 和桌面宽度无控件溢出；深浅背景与恢复记忆正确；不影响卡片滚动、选字、搜索、Badge、分组、阅读面板；透明卡片效果可接受；禁脚本、离线和打印行为符合上述范围。独立专项为 `pnpm test:watermark`，并结合 `pnpm check` 及受影响的既有浏览器回归。
